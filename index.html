Kebijakan Privasi — File Manager

Terakhir diperbarui: 27 September 2026

Kami menghargai privasi Anda. Kebijakan ini menjelaskan bagaimana aplikasi File Manager ("aplikasi", "kami") menangani data saat Anda menggunakannya di perangkat Android.

1. Ringkasan Singkat

  • Aplikasi tidak mengumpulkan, mengunggah, atau mengirim file, nama file, maupun isi folder Anda ke server kami — semua operasi file terjadi langsung di perangkat Anda.
  • Aplikasi tidak meminta akun, nama, email, atau nomor telepon.
  • Data preferensi (folder favorit, riwayat file terbaru, pengaturan tampilan) disimpan hanya di penyimpanan lokal perangkat dan tidak pernah dikirim ke mana pun.
  • Iklan pihak ketiga (Google AdMob) dapat mengumpulkan data tertentu sesuai kebijakan mereka — lihat bagian 5.

2. Izin yang Diminta dan Tujuannya

  • All files access / Storage (READ & WRITE_EXTERNAL_STORAGE, MANAGE_EXTERNAL_STORAGE) — diperlukan agar aplikasi dapat membaca, menyalin, memindah, mengganti nama, mengompres, dan menghapus file/folder di penyimpanan internal maupun SD card, sesuai permintaan Anda. Aplikasi tidak membaca file tanpa Anda menavigasinya.
  • Internet (INTERNET) — digunakan solely untuk menayangkan iklan dari Google AdMob. Tidak ada data file yang dikirim melalui internet.

3. Data yang Disimpan di Perangkat (Lokal)

  • Folder favorit dan daftar file terakhir dibuka — disimpan via penyimpanan lokal aplikasi (SharedPreferences), hanya berupa path/jalur folder atau file.
  • Preferensi pengaturan — mode urutan, tampilan daftar, dan opsi file tersembunyi.
  • Recycle Bin — file yang Anda hapus dipindah sementara ke folder tersembunyi .TrashFileManager di storage terkait, dan dapat dipulihkan. Mengosongkan Recycle Bin menghapusnya permanen.

Seluruh data di atas hilang permanen saat Anda meng-uninstall aplikasi atau menekan "Clear data". Kami tidak memiliki salinannya.

4. Data yang TIDAK Kami Kumpulkan

  • Isi, nama, atau metadata file Anda tidak pernah dikirim ke server kami.
  • Tidak ada analitik pihak ketiga yang dipasang oleh kami.
  • Tidak ada pelacakan lokasi, kontak, kamera, mikrofon, atau SMS.

5. Iklan (Google AdMob)

Aplikasi ini menampilkan iklan dari Google AdMob (Google LLC) untuk mendukung pengembangan gratis. Google dapat mengumpulkan dan memproses data seperti Advertising ID, perangkat, dan data interaksi iklan sesuai:

  • Kebijakan Privasi Google
  • Cara Google menggunakan data dari situs/aplikasi yang memakai layanan Google

Anda dapat menonaktifkan personalisasi iklan lewat Pengaturan Android → Google → Iklan → Opt out of Ads Personalization, atau menghapus/mengatur ulang Advertising ID di pengaturan perangkat.

6. Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun (atau usia minimum setara di yurisdiksi Anda) dan tidak sengaja mengumpulkan data dari anak-anak.

7. Keamanan

Karena semua operasi file bersifat lokal di perangkat, risiko kebocoran ke pihak luar sangat minim. Kami menyarankan Anda selalu memperbarui aplikasi dan sistem operasi ke versi terbaru.

8. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Versi terbaru selalu tersedia di halaman ini dan di dalam aplikasi (Pengaturan → Kebijakan privasi).
